# Security policy

Please report security issues privately (GitHub "Report a vulnerability" on this repository) rather than in a
public issue, or by e-mail to zapytania@formawizualna.pl. <!-- privacy-scan: allow (public contact) -->
Relevant areas: LE Audio encryption (CCM keys, bonding), HCI command handling on the C6, and the OTA
update path.

Do not include bonding keys, device addresses or network credentials in reports or logs.
